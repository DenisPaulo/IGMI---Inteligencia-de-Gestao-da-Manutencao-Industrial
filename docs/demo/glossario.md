# Glossário (português simples)

| Termo | O que quer dizer |
|---|---|
| **OS (ordem de serviço)** | o pedido de trabalho da manutenção: o que fazer, em qual equipamento, quando e por quem (função) |
| **Tarefa / apontamento** | cada pedaço de trabalho registrado dentro da OS, com função técnica e minutos gastos |
| **Corretiva emergencial** | quebrou e precisa de atendimento agora; quase sempre para a linha |
| **Corretiva planejada** | defeito que pode esperar um pouco; é planejado e programado antes de executar |
| **Preventiva** | tarefa de um plano feita por tempo ou uso (ex.: lubrificar a cada 30 dias) |
| **Preditiva / inspeção** | medir a condição (vibração, temperatura, vácuo) para pegar a falha antes de ela acontecer |
| **Melhoria** | mudar algo para a falha não voltar ou para facilitar a manutenção |
| **Backlog** | o trabalho que ainda não foi feito; medido em semanas de trabalho da equipe |
| **Plano preventivo** | lista de tarefas com periodicidade, horas estimadas, especialidade e tolerância |
| **PM compliance** | quantas preventivas foram feitas dentro do prazo, entre as que já venceram |
| **Aderência à programação** | quanto do que foi programado para a semana foi feito na própria semana |
| **MTBF** | tempo médio entre falhas: quanto tempo, em média, o equipamento roda sem quebrar |
| **MTTR** | tempo médio para reparar: quanto tempo, em média, a linha fica parada por falha |
| **Disponibilidade** | parte do tempo programado em que a linha estava pronta para produzir |
| **Pareto** | ranking das falhas que mais pesam; poucas causas costumam explicar a maior parte da perda |
| **Reincidência** | a mesma falha voltando no mesmo lugar em pouco tempo (aqui: 3 vezes em 15 dias) |
| **Modo de falha** | o que se vê: "não pega a peça", "travou", "sem vácuo" |
| **Causa** | por que aconteceu: desgaste, erro de operação, instalação, projeto… |
| **Mecanismo** | o processo físico: desgaste, fadiga, sujeira, falha elétrica… |
| **Criticidade A/B/C** | quanto o equipamento importa: A para a linha ou afeta segurança/qualidade; C pouco impacta |
| **Curva P-F** | a janela entre o primeiro sinal de problema (P) e a quebra (F); a inspeção tem de ser mais frequente que essa janela |
| **Subconjunto** | parte de um equipamento (ex.: a garra do robô, a correia do transportador) |
| **Centro de custo** | código contábil da linha; aqui é fictício (`SINT-CC-…`) |
| **Dados sintéticos** | dados inventados por um programa, com aparência real, para testar e demonstrar sem expor nada da fábrica |
